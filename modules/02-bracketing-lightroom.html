5-Stop HDR Bracketing & Lightroom Merge

Complete field and editing tutorial: shooting −2 to +2 EV with bracket5_opt.lua and developing 32-bit DNGs

When & Why to Use 5-Stop Bracketing

Use 5-stop bracketing whenever your scene has extreme contrast that exceeds the sensor's 11.8-stop limit:

  • Sunsets or sunrises with dark landscape foregrounds.
  • Looking from inside a dark room, cave, or archway out into bright sunlight.
  • High-contrast mountain scenes with bright snow and deep shadow ravines.

The script fires 5 consecutive RAW images spaced 1 stop apart: −2 EV, −1 EV, 0 EV, +1 EV, +2 EV. Shutter speed changes automatically while aperture stays strictly locked at f/8.

Field Tutorial: Shooting the 5-Stop Bracket

1

Camera Mode & Aperture

Set mode dial to Av (Aperture Priority) or M (Manual). Set aperture to f/8 (peak lens sharpness) and ISO to 100.

2

Frame & Half-Press Meter

Frame your shot on the tripod. Half-press the shutter once so the camera meters the scene's baseline (0 EV) shutter speed.

3

Load bracket5_opt.lua

Press M-Fn (<ALT>) → MENU → Script → Load Script from File... → select bracket5_opt.lua.

4

Configure Parameters

Verify settings: Step size (EV) = 1, Timer Delay = 2 (seconds), Target ISO = 100.

5

Press Shutter & Hands Off!

Press MENU to close. Press the Shutter button. The camera waits 2s to kill vibration, locks autofocus, fires all 5 frames, and restores your settings.

Computer Tutorial: Merging into 32-bit HDR in Lightroom

Follow these exact steps inside Adobe Lightroom Classic or Lightroom CC:

1

Import RAW Files
Import the 5 .CR2 files from your SD card into Lightroom.

→
2

Select All 5
In Library Grid (G), Shift-click the 5 bracketed frames to highlight them.

→
3

Press Cmd + H
Right-click → Photo Merge → HDR (Shortcut: Cmd + H on Mac / Ctrl + H on Win).

→
4

Configure Dialog
Check Auto Align. Set Deghost to Low (or None). Check Auto Settings.

→
5

Merge 32-Bit DNG
Click Merge. Lightroom creates a new [filename]-HDR.dng file.

🎛️
Developing the 32-Bit DNG in Lightroom Develop Module (D)

Because the output is a true 32-bit raw file, the Develop sliders give you unmatched recovery latitude:

  • Highlights (−50 to −80): Brings back full sky gradient, sun flare detail, and cloud texture without muddy grays.
  • Shadows (+30 to +60): Pulls clean foreground shadow details out of the darks with zero chrominance noise.
  • White/Black Clipping: Hold the Option key (Mac) / Alt key (Win) while dragging the Whites and Blacks sliders to set clean pure-white and pure-black endpoints.

Field Troubleshooting & Pro-Tips

Issue Cause Solution
Lightroom shows ghosting blur Wind blew foliage between shots In the HDR Merge dialog, set Deghosting to Medium or High.
Script stops after frame 1 Image Review is active Disable Image Review in Canon Menu → Shoot Tab 1.
Exposure steps look uneven Auto-ISO fought the script Set ISO manually in Canon mode or verify Target ISO = 100 in script.
