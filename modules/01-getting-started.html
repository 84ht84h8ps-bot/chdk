Camera Prep & CHDK Quickstart

Complete physical checklist and navigation fundamentals before running any script

Step 1: Mandatory Canon Physical & Menu Setup

Before launching CHDK or mounting on your tripod, configure these exact settings in the native Canon menu. If these are not configured, auto-algorithms will fight the scripts:

🛑

1. Lens IS → OFF

Turn off Image Stabilization using the physical lens switch or in Canon Menu → Shoot Tab 1 → IS Settings → Off. On a tripod, IS sensors create feedback loops that cause micro-blur.

🎨

2. Lock White Balance

Set White Balance to Daylight (5200K) for daytime/panoramas, or Tungsten/4000K for astrophotography. Never leave on AWB (Auto), or colors will shift between frames.

⚡

3. Image Quality → RAW

In native Canon Menu → Shoot Tab 1 → Image Quality, select RAW. This produces native 14-bit .CR2 files with full sensor dynamic range.

⏱️

4. Image Review → OFF

Canon Menu → Shoot Tab 1 → Image Review → Off. Disabling post-shot LCD playback prevents the camera from freezing between fast interval shots.

Step 2: Operating CHDK on the EOS M3

CHDK runs as a transparent overlay in camera RAM. Learn the 3 key button actions:

M-Fn

Toggle <ALT> Mode
Press the M-Fn button (next to shutter). <ALT> appears at screen bottom.

→
MENU

Open CHDK Menu
While <ALT> is showing, press MENU. Navigate with the D-pad and press SET to select.

→
SHUTTER

Run / Stop Script
Exit menu (press MENU). While <ALT> is showing, press Shutter to start. Press again to abort.

💡
One-Time Prerequisite: Enable Lua Native Calls

In CHDK Menu → Miscellaneous stuff → scroll to Enable Lua Native Calls → press SET to check [ * ]. This is required for our scripts to control EF-M electronic lens motors.

Step 3: Loading Any Script in 10 Seconds

  1. Press M-Fn so <ALT> appears at the bottom of your LCD.
  2. Press MENU to open the CHDK menu.
  3. Scroll to Script and press SET.
  4. Select Load Script from File... → press SET.
  5. Choose your script (e.g. fixedint.lua, bracket5_opt.lua, pano_helper.lua, focus_stack.lua) and press SET.
  6. Adjust the script parameters right on screen using Left/Right on the dial.
  7. Press MENU to close. With <ALT> still displayed, press the Shutter button to start shooting!
