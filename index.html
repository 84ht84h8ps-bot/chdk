Camera Prep & CHDK Quickstart

Complete physical checklist and navigation fundamentals before running any script

Step 1: Mandatory Canon Physical & Menu Setup

Before launching CHDK or mounting on your tripod, configure these exact settings in the native Canon menu. If these are not configured, auto-algorithms will fight the scripts:

🛑

1. Lens IS → OFF

Turn off Image Stabilization using the physical lens switch or in Canon Menu → Shoot Tab 1 → IS Settings → Off. On a tripod, IS sensors create feedback loops that cause micro-blur.

🎨

2. Lock White Balance

Set White Balance to Daylight (5200K) for daytime/panoramas, or Tungsten/4000K for astrophotography. Never leave on AWB (Auto), or colors will shift between frames.

⚡

3. Image Quality → RAW

In native Canon Menu → Shoot Tab 1 → Image Quality, select RAW. This produces native 14-bit .CR2 files with full sensor dynamic range.

⏱️

4. Image Review → OFF

Canon Menu → Shoot Tab 1 → Image Review → Off. Disabling post-shot LCD playback prevents the camera from freezing between fast interval shots.

Step 2: Operating CHDK on the EOS M3

CHDK runs as a transparent overlay in camera RAM. Learn the 3 key button actions:

M-Fn

Toggle <ALT> Mode
Press the M-Fn button (next to shutter). <ALT> appears at screen bottom.

→
MENU

Open CHDK Menu
While <ALT> is showing, press MENU. Navigate with the D-pad and press SET to select.

→
SHUTTER

Run / Stop Script
Exit menu (press MENU). While <ALT> is showing, press Shutter to start. Press again to abort.

💡
One-Time Prerequisite: Enable Lua Native Calls

In CHDK Menu → Miscellaneous stuff → scroll to Enable Lua Native Calls → press SET to check [ * ]. This is required for our scripts to control EF-M electronic lens motors.

Step 3: Loading Any Script in 10 Seconds

  1. Press M-Fn so <ALT> appears at the bottom of your LCD.
  2. Press MENU to open the CHDK menu.
  3. Scroll to Script and press SET.
  4. Select Load Script from File... → press SET.
  5. Choose your script (e.g. fixedint.lua, bracket5_opt.lua, pano_helper.lua, focus_stack.lua) and press SET.
  6. Adjust the script parameters right on screen using Left/Right on the dial.
  7. Press MENU to close. With <ALT> still displayed, press the Shutter button to start shooting!

5-Stop HDR Bracketing & Lightroom Merge

Complete field and editing tutorial: shooting −2 to +2 EV with bracket5_opt.lua and developing 32-bit DNGs

When & Why to Use 5-Stop Bracketing

Use 5-stop bracketing whenever your scene has extreme contrast that exceeds the sensor's 11.8-stop limit:

  • Sunsets or sunrises with dark landscape foregrounds.
  • Looking from inside a dark room, cave, or archway out into bright sunlight.
  • High-contrast mountain scenes with bright snow and deep shadow ravines.

The script fires 5 consecutive RAW images spaced 1 stop apart: −2 EV, −1 EV, 0 EV, +1 EV, +2 EV. Shutter speed changes automatically while aperture stays strictly locked at f/8.

Field Tutorial: Shooting the 5-Stop Bracket

1

Camera Mode & Aperture

Set mode dial to Av (Aperture Priority) or M (Manual). Set aperture to f/8 (peak lens sharpness) and ISO to 100.

2

Frame & Half-Press Meter

Frame your shot on the tripod. Half-press the shutter once so the camera meters the scene's baseline (0 EV) shutter speed.

3

Load bracket5_opt.lua

Press M-Fn (<ALT>) → MENU → Script → Load Script from File... → select bracket5_opt.lua.

4

Configure Parameters

Verify settings: Step size (EV) = 1, Timer Delay = 2 (seconds), Target ISO = 100.

5

Press Shutter & Hands Off!

Press MENU to close. Press the Shutter button. The camera waits 2s to kill vibration, locks autofocus, fires all 5 frames, and restores your settings.

Computer Tutorial: Merging into 32-bit HDR in Lightroom

Follow these exact steps inside Adobe Lightroom Classic or Lightroom CC:

1

Import RAW Files
Import the 5 .CR2 files from your SD card into Lightroom.

→
2

Select All 5
In Library Grid (G), Shift-click the 5 bracketed frames to highlight them.

→
3

Press Cmd + H
Right-click → Photo Merge → HDR (Shortcut: Cmd + H on Mac / Ctrl + H on Win).

→
4

Configure Dialog
Check Auto Align. Set Deghost to Low (or None). Check Auto Settings.

→
5

Merge 32-Bit DNG
Click Merge. Lightroom creates a new [filename]-HDR.dng file.

🎛️
Developing the 32-Bit DNG in Lightroom Develop Module (D)

Because the output is a true 32-bit raw file, the Develop sliders give you unmatched recovery latitude:

  • Highlights (−50 to −80): Brings back full sky gradient, sun flare detail, and cloud texture without muddy grays.
  • Shadows (+30 to +60): Pulls clean foreground shadow details out of the darks with zero chrominance noise.
  • White/Black Clipping: Hold the Option key (Mac) / Alt key (Win) while dragging the Whites and Blacks sliders to set clean pure-white and pure-black endpoints.

Field Troubleshooting & Pro-Tips

Issue Cause Solution

60-Shot Astrophotography & Siril Stacking

Complete field and post-processing tutorial: shooting with fixedint.lua and processing in Siril & Lightroom

Step 1: Calculate Your Max Exposure (500 Rule)

To prevent stars from turning into blurry streaks due to Earth's rotation, use the 500 Rule tailored to the EOS M3's 1.6× crop factor:

Max_Seconds = 500 / (Focal_Length × 1.6)

Lens / Focal Length Calculation Safe Shutter Speed
EF-M 11-22mm @ 11mm 500 / (11 × 1.6) = 28.4s 20s to 25s
EF-M 15-45mm @ 15mm 500 / (15 × 1.6) = 20.8s 15s to 20s
EF-M 22mm f/2 STM 500 / (22 × 1.6) = 14.2s 13s to 15s

Step 2: Field Focusing with 10× Live View Zoom

Autofocus cannot see in the dark, and lens infinity marks are physically inaccurate. Focus using this exact technique:

1

Switch to MF

Set lens to MF (Manual Focus). Aperture wide open (e.g. f/2, f/3.5). ISO to 3200.

2

Zoom 10× on Bright Star

Center the brightest star in the sky on your LCD. Press the blue Magnify button on the back twice for 10× zoom.

3

Dial Down to Tiny Pinpoint

Turn the focus ring slowly. The star will shrink from a blurry blob into a tiny, sharp dot. When it is as small as possible, stop.

4

Tape the Focus Ring

Apply a strip of tape across the focus ring so your hands don't accidentally bump it during the 60-shot sequence.

Step 3: Configuring fixedint.lua in CHDK

  1. Press M-Fn (<ALT>) → MENU → Script → Load Script from File... → choose fixedint.lua.
  2. Set Shots (0=unlimited) to 60 (about 15-20 minutes total capture).
  3. Set Interval Sec/10 to 0 (captures back-to-back with zero dead-time).
  4. Set Tv to 15 or 20 (matching your 500-rule calculation).
  5. Set Disable Canon Dark Frame to true (CRUCIAL: prevents 15s freeze between shots).
  6. Set Display to Blt_Off (kills LCD backlight: cuts sensor thermal noise and saves battery).
  7. Set Start delay (ms) to 3000 (3 seconds for tripod vibrations to settle).
  8. Set Shutdown on low battery to true (safely flushes SD card if battery dies).
  9. Press MENU to close. Press the Shutter button to start the 60-shot run!

Step 4: Stacking & Calibrating in Siril (macOS)

1

Set Working Directory
Open Siril. Click the Home icon and choose your folder containing the 60 .CR2 files.

→
2

Run OSC Script
Go to Scripts → OSC_Preprocessing_WithoutDBF. Siril aligns stars and auto-erases satellite trails with Winsorized clipping!

→
3

Background Extraction
Open result.fit. Go to Image Processing → Background Extraction → Generate Grid → Apply (kills light pollution gradients).

→
4

Photometric Calibration
Go to Image Processing → Photometric Color Calibration (PCC). Type target coordinates to auto-calibrate true star colors.

→
5

Asinh Stretch & Export
Go to Image Processing → Asinh Transformation to stretch faint Milky Way dust. Save as 16-bit TIFF.

Step 5: Final Creative Polish in Lightroom

Import your 16-bit TIFF output from Siril into Lightroom:

  • Dehaze (+10 to +20): Strips away lingering atmospheric haze and makes the Milky Way pop.
  • Clarity (+15) & Texture (+10): Accentuates dust lanes and dark nebula structures.
  • Noise Reduction → Luminance: Set to 0! Because you stacked 60 frames in Siril, the background noise is already mathematically eliminated.
  • Radial Mask: Draw an oval over the galactic core, boost Exposure by +0.3 and Warmth by +5.

Panoramic Landscape & Lightroom Stitching

Step-by-step field execution with pano_helper.lua and seamless stitching in Lightroom

Step 1: Physical Tripod & Camera Alignment

📐

Mount Vertically (Portrait)

Mount your camera in portrait orientation using an L-bracket or tilted tripod head. Vertical frames give you 6000 vertical pixels of resolution and natural landscape proportions.

⚖️

Level Your Tripod Base

Ensure your tripod head rotates on a perfectly horizontal plane. If the tripod is tilted, your panoramic sweep will curve like a banana, forcing severe cropping.

🎯

Lock Camera Settings

Dial to M (Manual) at f/8, ISO 100. White Balance set to Daylight (5200K)—never Auto White Balance!

Step 2: Shooting with pano_helper.lua

This script completely prevents exposure and focus shifts between panels and paces your tripod rotations with audio beeps:

  1. Aim the camera at the primary midtone region of your vista.
  2. Press M-Fn (<ALT>) → MENU → Script → Load Script from File... → select pano_helper.lua.
  3. Set Number of Pano Panels to 6 (or your chosen count covering your sweep with 30% overlap).
  4. Set Pause to Rotate Tripod (sec) to 4.
  5. Set Bracket Each Panel? to 0 (standard single exposure).
  6. Press MENU to close. Frame your first panel (far left) and press the Shutter button.
  7. Listen for the Beep:
    • The camera meters and locks exposure and focus, then shoots Panel 1.
    • You will hear an audio BEEP!
    • Smoothly turn your tripod head to the right by ~30% overlap during the 4-second pause.
    • Take your hands off the camera. Panel 2 fires automatically.
    • Repeat until the script double-beeps to signal the panorama is complete!

Step 3: Stitching the Panorama in Lightroom

1

Select Panels
In Lightroom Library grid (G), select all 6 panels.

→
2

Press Cmd + M
Right-click → Photo Merge → Panorama (Shortcut: Cmd + M).

→
3

Choose Cylindrical
Select Cylindrical Projection (keeps the horizon straight without spherical bowing).

→
4

Boundary Warp
Drag Boundary Warp to 80-90 to pull edges into the corners, or check Fill Edges.

→
5

Merge
Click Merge. Lightroom creates an 80+ megapixel -Pano.dng RAW file!

Panorama Field Gotchas & Troubleshooting

Problem Cause Solution
Lightroom says “Unable to merge” Overlap between panels was too small (<25%) Turn tripod less between shots; ensure 30% to 40% overlap between adjacent frames.
Sky has vertical stripes White Balance or Shutter changed Always use pano_helper.lua and lock WB to Daylight in Canon menu.
Foreground objects don't align Parallax error (camera pivoted behind lens nodal point) Keep prominent foreground rocks at least 2 meters away when panning on a standard tripod head.

Masterclass: HDR Panorama on the EOS M3

Complete step-by-step tutorial: shooting the exposure matrix with pano_helper and 1-click merging in Lightroom

The Concept: The Exposure Matrix

An HDR Panorama combines multi-exposure bracketing with panoramic stitching. When shooting into high-contrast sunsets, single-exposure panoramas blow out the sun or plunge foregrounds into black noise.

By shooting a 3-stop bracket (−2 EV, 0 EV, +2 EV) at every single rotation angle, you capture the entire 160° landscape with zero blown highlights and zero noisy shadows:

6 Panels × 3 Bracketed Exposures = 18 RAW Frames Total

Step 1: Shooting the HDR Matrix with pano_helper.lua

  1. Mount your camera vertically on your tripod. Set mode dial to M (Manual) at f/8, ISO 100.
  2. Set White Balance to Daylight (5200K) in the Canon menu.
  3. Press M-Fn (<ALT>) → MENU → Script → Load Script from File... → select pano_helper.lua.
  4. Configure these exact parameters:
    • Number of Pano Panels: 6
    • Pause to Rotate Tripod (sec): 5 (gives a comfortable window to rotate smoothly)
    • Bracket Each Panel?: Set to 1 ← CRUCIAL: Enables HDR bracketing at each angle!
  5. Press MENU to exit. Aim at your starting frame (far left) and press the Shutter button.
  6. The Shooting Cycle:
    • The camera locks settings and fires 3 rapid bracketed shots: −2 EV (sky), 0 EV (midtones), and +2 EV (shadows).
    • You hear a BEEP!
    • Smoothly rotate your tripod head to the right by ~30% overlap during the 5-second pause.
    • Take your hands off. The camera automatically fires the next 3 bracketed shots!
    • Repeat across all 6 panels until the script finishes.

Step 2: Lightroom's 1-Click “HDR Panorama” Merge

Do not waste time manually merging each 3-shot bracket first. Lightroom has a dedicated engine that merges brackets and stitches the panorama simultaneously:

1

Select All 18 RAWs
In Lightroom Library grid (G), select all 18 files from the session at once.

→
2

Cmd + Shift + M
Right-click → Photo Merge → HDR Panorama (Shortcut: Cmd + Shift + M on Mac / Ctrl + Shift + M on Win).

→
3

Lightroom AI Engine
Lightroom groups the 18 frames into 6 brackets, creates 32-bit HDRs in RAM, and stitches the vista in one pass!

→
4

Select Cylindrical
Choose Cylindrical projection, set Boundary Warp to 80-90, and check Fill Edges.

→
5

Merge 100MP DNG
Click Merge. Lightroom creates a single colossal -HDRPano.dng file!

Step 3: Developing Your 32-Bit HDR Panorama

Open the new -HDRPano.dng file in Lightroom's Develop Module (D):

  • Highlights (−60 to −90): The blazing sun and sunset clouds reveal incredible orange and purple textures without gray muddy clipping.
  • Shadows (+30 to +50): Dark foreground trees and rocks emerge with crystal clarity and zero chrominance noise because they were exposed at +2 EV in the bracket!
  • Dehaze (+10) & Clarity (+15): Cuts atmospheric haze across distant mountains while maintaining natural foreground colors.
  • Zoom to 100%: Pan across your 100+ megapixel image to inspect tack-sharp leaves, branches, and rock textures miles in the distance.

Infinite Focus Stacking with focus_stack.lua

Complete step-by-step tutorial: automated EF-M lens focus racking and depth-of-field blending in Photoshop

The Optics: Why f/8 Stacking Beats f/22

Landscape photographers often stop down to f/22 to get everything in focus, but the resulting image is soft and blurry across the entire frame. This is caused by optical diffraction: on the EOS M3's tiny 3.72-micron pixels, light waves passing through a tiny f/22 pinhole bend and smear fine details across adjacent pixels.

By shooting multiple frames at the lens's optical sweet spot (f/8) while stepping the focus motor incrementally from foreground to infinity, you get infinite depth of field with 3× higher optical sharpness!

Step 1: Mandatory EOS M3 Settings & Running focus_stack.lua

⚠️
3 Required Settings on the Canon EOS M3 Before Focus Stacking

Unlike PowerShot compacts, the EOS M3 does not support CHDK's standard set_focus() override. It drives electronic Canon EF-M lenses directly via Canon's internal FA.Create / EFLensCom.MoveFocus firmware routines. You must set these 3 options once:

  1. Enable Lua Native Calls in CHDK: Press M-Fn (<ALT>) → MENU → Miscellaneous stuff → check Enable Lua Native Calls [ • ] (press SET on "Are you sure?").
  2. Set Canon Focus Mode to MF: EF-M lenses have no physical AF/MF switch on the barrel. Exit <ALT> mode, press Q / SET → set Focus Mode to MF (Manual Focus), and in the Canon Menu set Continuous AF: Off (otherwise half-pressing the shutter re-autofocuses every shot!).
  3. Use an Electronic EF-M (or Adapted EF/EF-S) Lens: Manual-only third-party lenses (e.g. TTArtisan/7Artisans) have no internal stepper motor.
  1. Mount your camera on a steady tripod. Set mode dial to M or Av at f/8, ISO 100.
  2. In Canon MF mode, turn the focus ring to focus sharply on the closest object in your foreground (or set Start Position = 1 (Near/MFD) to let the script drive the lens to Minimum Focus Distance automatically).
  3. Press M-Fn (<ALT>) → MENU → Script → Load Script from File... → select focus_stack.lua.
  4. Verify script parameters:
    • Start Position (0=Current, 1=Near/MFD): 0 (starts from your current foreground focus) or 1 (drives to MFD first)
    • Max Shots (Safety Cap): 15
    • Initial Step Size (Motor Steps): 25
    • Step Growth % per Shot: 40 (progressively widens motor steps as depth of field expands with distance)
    • Final True-Infinity Shot: 1 (Yes) (drives lens to optical infinity via EFLensCom.FocusSearchFar for the final frame)
    • Initial Delay: 2 (seconds)
  5. Press MENU to exit. Press the Shutter button.
  6. Automated Execution:
    • The script initializes FA.Create & InitializeAdjustmentSystem, forces set_mf(1), locks exposure (Tv/Av), and captures your close foreground.
    • On each step, it drives the EF-M lens outward via EFLensCom.MoveFocus with +40% progressive step growth, displaying live motor step position and Canon focus distance (e.g. 25cm → 60cm → 1.8m → INF) on screen.
    • As soon as Canon reports optical infinity (81m+) or the motor hits the infinity stop, it stops early so no duplicate frames are wasted, and finishes with a guaranteed True Infinity frame via EFLensCom.FocusSearchFar!
